# HivePanel Worker

The HivePanel Worker is the node agent responsible for running Cells.

## Features

- UUID-based Cells
- Combs (template system)
- Dynamic installer engine
- Live console
- File manager
- Process runtime
- Runtime abstraction (Process/Docker)
- REST API
- WebSocket console

## Roadmap

- Docker runtime
- Queen (control panel)
- Swarm clustering
- Backups
- Scheduled tasks
- Allocation manager
- Metrics
